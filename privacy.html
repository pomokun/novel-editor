プライバシーポリシー

最終更新日: 2026年9月27日

このページでは、「小説エディタ」（以下「本アプリ」）が Google ユーザーデータをどのように扱うかを説明します。

1. アクセスするデータ

本アプリは、Googleドライブ連携のために次のスコープへのアクセスを求めます。

  • https://www.googleapis.com/auth/drive.file
    本アプリが作成したファイルとフォルダ（ドライブ内の「小説エディタ」フォルダとその中の原稿）にだけアクセスします。 ドライブ上のほかのファイルにはアクセスしません。

2. データの使い方

  • 利用者が書いた原稿を、利用者自身のGoogleドライブに保存し、読み込むためだけに使います。
  • 他の端末（スマートフォンなど）で原稿が更新されたかどうかを確認するため、ファイル名と更新日時を取得します。
  • 広告、分析、機械学習の学習データなど、上記以外の目的には使いません。

3. データの保存場所

  • 原稿は利用者のPCと、利用者自身のGoogleドライブにのみ保存されます。
  • Googleアカウントへのログイン情報（リフレッシュトークン）は、利用者のPC内に Windows の暗号化機能で暗号化して保存します。
  • 本アプリの開発者が運営するサーバーは存在せず、データが開発者や第三者に送信されることはありません。

4. データの共有

Google ユーザーデータを第三者に販売、譲渡、共有することはありません。

5. データの削除とアクセスの取り消し

  • 本アプリの「ドライブ」メニューの「ログアウト」で、PC内のログイン情報を削除し、アクセス権を取り消せます。
  • Googleアカウントのサードパーティ製アプリの管理ページ からも、いつでもアクセス権を取り消せます。
  • ドライブ上の原稿は、Googleドライブから通常の方法で削除できます。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用に関する要件を含む）に準拠します。
