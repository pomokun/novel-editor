小説エディタ

縦書き二段組のプレビューが付いた、Windows向けの個人用テキストエディタです。

Windows版をダウンロード

「novel-editor-setup-(バージョン).exe」を実行するとインストールされます（インストール不要で使いたい場合は「portable」の方を）。 初回起動時に「WindowsによってPCが保護されました」と表示されたら、「詳細情報」→「実行」を押してください。 新しいバージョンはアプリが自動でダウンロードして更新します。

主な機能

  • プレーンテキストでの原稿執筆
  • 縦書き二段組のプレビュー表示
  • 文字数・ページ数・原稿用紙換算枚数の表示
  • Googleドライブとの同期（原稿をGoogleドキュメントとして保存し、スマートフォンからも編集できます）

Googleドライブの利用について

このアプリは https://www.googleapis.com/auth/drive.file スコープのみを使います。 アクセスできるのは、このアプリで作成したファイル（ドライブ内の「小説エディタ」フォルダとその中の原稿）だけです。 ドライブ上のほかのファイルを見たり変更したりすることはありません。
